## 结论

Java 管理数据库连接的包是 **`java.sql`**（JDBC 标准 API），连接池则常用 **`javax.sql`** 里的 `DataSource`。

## 核心用法（最基础的 JDBC 五步）

```java
import java.sql.*;   // 就是 java.sql 包

public class Demo {
    public static void main(String[] args) throws Exception {
        // 1. 加载驱动（JDBC 4.0+ 可省略，会自动加载）
        Class.forName("com.mysql.cj.jdbc.Driver");

        // 2. 获取连接：URL + 用户名 + 密码
        String url = "jdbc:mysql://localhost:3306/testdb?serverTimezone=Asia/Shanghai";
        Connection conn = DriverManager.getConnection(url, "root", "123456");

        // 3. 创建语句对象
        PreparedStatement ps = conn.prepareStatement("select id, name from user where id = ?");
        ps.setInt(1, 1);

        // 4. 执行并读结果
        ResultSet rs = ps.executeQuery();
        while (rs.next()) {
            System.out.println(rs.getInt("id") + " : " + rs.getString("name"));
        }

        // 5. 关闭（用 try-with-resources 更好，会自动关）
        rs.close(); ps.close(); conn.close();
    }
}
```

## 关键类（都在 `java.sql`）

| 类/接口                           | 作用                         |
| --------------------------------- | ---------------------------- |
| `DriverManager`                   | 根据 URL 拿到 `Connection`   |
| `Connection`                      | 一条数据库连接               |
| `Statement` / `PreparedStatement` | 执行 SQL（推荐后者，防注入） |
| `ResultSet`                       | 查询结果集                   |
| `SQLException`                    | 所有数据库异常               |

## 实际项目怎么做

不要每次 `DriverManager.getConnection()`（每次新建连接、很慢），而是用**连接池**：

- 接口在 `javax.sql.DataSource`
- 常用实现：**HikariCP**（Spring Boot 默认）、Druid、DBCP

```java
HikariDataSource ds = new HikariDataSource();
ds.setJdbcUrl("jdbc:mysql://localhost:3306/testdb");
ds.setUsername("root");
ds.setPassword("123456");

try (Connection conn = ds.getConnection()) {   // 从池里借，用完自动还
    // 同样的 JDBC 操作
}
```

再往上就是框架层，无需手写：MyBatis（`SqlSession`）、JPA / Hibernate（`EntityManager`），Spring 里用 `JdbcTemplate`。

## 一句话总结

> **`java.sql` 是 JDBC 核心包**，用 `DriverManager` 或 `DataSource` 拿 `Connection`，再走 `PreparedStatement` → `ResultSet`；生产环境用连接池（`javax.sql.DataSource` + HikariCP）而不是直连。
